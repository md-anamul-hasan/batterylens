# BatteryLens privacy policy

_Last updated: 2026-10-22_

BatteryLens runs entirely on your PC. It makes no network connections: no telemetry, no update check, nothing is uploaded. It reads local battery and power data through WMI, the Windows power-status API and `powercfg`, and writes an HTML report to your Desktop only when you press Export report or generate the Windows battery report.

There is no account, no licence key, no analytics and no crash reporting. Logs stay on your machine in `%APPDATA%\BatteryLens`.
